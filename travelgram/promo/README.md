# Vídeo promocional — Travelgram (15s)

- `travelgram-promo-15s.mp4` — vídeo final, 1080x1920 (9:16), 30fps, H.264, sem áudio.
- `promo.html` — a animação. Abra no navegador para ver a prévia em loop.
- `render.mjs` — gera o MP4 quadro a quadro (requer Node, Playwright e ffmpeg):

```sh
node render.mjs
```

Roteiro: intro com o logo (0–2,6s) → destinos Veneza, Cinque Terre, Florença e Roma (2,6–7,6s)
→ perfil com contadores e galeria (7,6–11,4s) → chamada "Crie seu perfil grátis" (11,4–15s).
